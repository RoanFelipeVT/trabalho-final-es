# Testes de Caixa-Preta — Biblioteca

Projeto acadêmico de testes automatizados de caixa-preta da biblioteca `biblioteca-1.0.jar`, utilizando Java 17, Maven e JUnit 5.

## Como executar

É necessário ter Java 17 e Maven instalados.

Na pasta raiz do projeto, execute:

```bash
mvn clean test
```

Os resultados dos testes serão exibidos no terminal.
